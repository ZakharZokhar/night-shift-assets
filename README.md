# Night Shift — game assets

Images, music and sound effects for the browser game **Night Shift**.
The game loads these files through the jsDelivr CDN:

```
https://cdn.jsdelivr.net/gh/ZakharZokhar/night-shift-assets@<tag>/<path>
```

The folder layout mirrors the game's `public/` directory one-to-one.
Every release is pinned to a git tag (`v1`, `v2`, …), so files under a tag never
change. To ship updated assets, push the changes and create a new tag, then bump
the tag in the game.
